# Heavenly Sword Descent V2.1.5

## 版本类型
技能机制增强

## 本版本内容

### 1. 巨剑落地后保留
巨剑命中后不再立即消失，而是在命中位置继续存在一段时间。

默认保留时间：`4.0` 秒，可在 `config.yml` 中调整到 3–5 秒或其他数值。

### 2. 持续伤害
巨剑保留期间会周期性对落点范围内的生物造成持续伤害。

默认每 `10` ticks（0.5 秒）造成一次持续伤害，持续伤害倍率为普通分层伤害的 `0.10`。

持续伤害不会重复施加击退，避免目标被连续击飞。

### 3. 配置

```yaml
skill:
  linger:
    seconds: 4.0
    damage-interval-ticks: 10
    damage-multiplier: 0.10
```

- `seconds`：巨剑命中后保留时间。
- `damage-interval-ticks`：持续伤害间隔，20 ticks = 1 秒。
- `damage-multiplier`：每次持续伤害相对于对应区域普通伤害的倍率。

### 4. 状态流程

`CHARGING → FALLING → IMPACT → LINGERING → CLEANUP`

命中后进入 `LINGERING`，巨剑固定在命中位置；持续时间结束后才执行清理，因此技能释放状态会一直保持到巨剑消散。

## 测试重点

1. 巨剑正常释放并完成坠落。
2. 命中后巨剑继续存在约 4 秒。
3. 保留期间目标持续受到伤害。
4. 持续伤害不会反复击退目标。
5. 4 秒结束后巨剑正常消失。
6. 清理完成后技能状态解除，并可以按正常 CD 规则再次释放。
