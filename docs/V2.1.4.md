# Heavenly Sword Descent V2.1.4

## 版本类型
功能优化 / UI 优化

## 本版本内容

### 1. 隐藏聊天框技能提示
V2.1.4 不再使用聊天框显示“正在锁定目标”“蓄力开始”“巨剑坠落”以及冷却中的提示，避免技能释放时刷屏。

### 2. ActionBar 技能状态
技能状态改为显示在 Minecraft 物品栏上方的 ActionBar 区域。

释放期间显示：

`⚔ 天剑降临 释放中...`

冷却期间显示：

`⚔ 天剑降临 冷却：15.0s`

剩余时间以 0.1 秒精度更新。

### 3. 配置

`config.yml` 新增：

```yaml
skill:
  display:
    actionbar: true
    chat-message: false
```

当前实现默认使用 ActionBar；聊天框技能提示关闭。

### 4. 与 V2.1.3 的兼容
本版本不修改已经通过实机测试的巨剑模型 MT/Transformation 与坠落姿态。剑身垂直、剑尖向下的 V2.1.3 修复保持不变。
