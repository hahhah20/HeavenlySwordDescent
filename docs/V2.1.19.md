# V2.1.19

## 本版本处理的问题

最新实机视频再次确认：V2.1.18 的 `LEFT X90° + RIGHT Z-135°` 方案没有得到正确的“剑尖向下”姿态，画面中巨剑出现横向/错误姿态。

本版本不再继续叠加新的角度试错，而是直接回到 V2.1.14 的核心模型修正方案：

- 剑身保持垂直
- 剑尖向下
- 剑面根据释放者所在的水平位置转向释放者
- 玩家 Pitch 不参与模型姿态
- 前、后、左、右、斜向释放都使用同一套规则

## 模型变换

`SwordProjectile` 恢复独立双侧 ItemDisplay 变换：

- LEFT rotation：X 轴 `90°`
- RIGHT rotation：Z 轴 `45°`

V2.1.18 的 Z `-135°` 已移除，因为最新实机视频已经证明该方案仍然错误。

## 面向释放者

保留 V2.1.17/V2.1.18 已加入的水平朝向逻辑：

`巨剑位置 → 释放技能玩家`

只取 X/Z 平面向量计算 yaw，不读取玩家 Pitch。因此玩家抬头、低头不会让巨剑倾斜。

## 生命周期

同一姿态继续应用于：

- 蓄力
- 开始下落
- 下落移动
- 命中落地
- 落地驻留

真实 ItemDisplay 本体继续驻留至少 4 秒，并继续执行持续伤害。

## 当前验证状态

本版本已写入 GitHub 源码并完成版本号同步。

需要服务器实机再次确认：

1. 剑尖是否明确朝地面。
2. 剑身是否始终垂直。
3. 剑面是否始终朝向释放技能的玩家。
4. 从前后左右及斜向释放时是否保持相同姿态。
5. 抬头/低头时是否仍保持垂直。
