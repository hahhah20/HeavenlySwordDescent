# 天剑降临 V2.1.3

## 版本定位
剑尖方向与模型姿态修正版。

## 本版本改动
- 修正 ItemDisplay 中原版下界合金剑模型的朝向。
- 将巨剑姿态固定为朝向地面，避免使用视角 Billboard 导致方向偏移。
- 保持蓄力与坠落过程中姿态一致；坠落阶段只改变 Y 坐标。
- 保留 V2.1.2 已有的技能释放、冷却与清理逻辑。

## MT（模型变换 / Model Transform）
本版本同步调整 MT：
- LeftRotation：用于确定巨剑整体朝向。
- RightRotation：保持单位旋转，避免叠加额外姿态。
- Translation：用于后续模型中心与剑尖落点校准。
- Scale：保留现有巨剑尺寸比例，不改变技能伤害与坠落逻辑。
