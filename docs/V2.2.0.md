# V2.2.0 — 天剑降临完整版模块化版本

## 版本目标
V2.2.0 将天剑降临从单体实现拆分为技能编排、实体状态、模型显示、视觉效果、伤害处理和配置读取六个职责层，同时保留 V2.1.20 的剑身基准姿态与水平面向玩家逻辑。

## 最终模块结构

### 技能编排层
`skill/HeavenlySwordSkill.java`
- 负责目标锁定。
- 负责 `TARGET_LOCK -> CHARGING -> FALLING -> IMPACT -> LINGERING -> CLEANUP` 状态流转。
- 只调度实体、特效和伤害模块，不直接实现模型或伤害细节。

`skill/HeavenlySword.java`
- 保留为兼容旧调用方的薄封装。
- 实际执行委托给 `HeavenlySwordSkill`。

### 实体层
`entity/HeavenlySwordEntity.java`
- 管理巨剑高度、下落速度、加速度、落地位置和驻留状态。
- 对外提供 `spawn / charge / beginFall / tickFall / land / keepLanded / remove` 生命周期接口。
- 物理参数通过 `SkillConfig` 读取。

### 模型层
`model/SwordModelController.java`
- 专门管理 ItemDisplay。
- 保留 V2.1.20 的 `+135° Z` 固定剑身基准姿态。
- 水平面向释放者时只使用 X/Z 计算 yaw，玩家 Pitch 不参与。
- 统一负责缩放、传送、亮度、Billboard、Persistent 与 Invulnerable。

### 特效层
`effect/SwordEffectManager.java`
- 统一调度预警、天空能量、下落拖尾与落地冲击表现。
- `ImpactEffect` 已改为纯视觉模块，不再直接造成伤害。
- `WarningEffect`、`EnergyEffect`、`SwordTrail` 和裂纹数量均通过 V2.2.0 配置读取。

### 伤害层
`damage/SwordDamageHandler.java`
- 天剑技能唯一伤害入口。
- 分别提供首次落地伤害与驻留周期伤害。

`damage/DamageManager.java`
- 保留为底层分层伤害计算实现。
- 读取统一 `SkillConfig`，不再由特效类直接调用。

### 配置层
`config/ModuleConfig.java`
- 加载 V2.2.0 拆分配置文件。

`config/SkillConfig.java`
- 对技能其余模块提供统一配置访问。
- 新配置缺失时继续兼容旧 `config.yml` 数值。

新增资源：
- `skills.yml`：技能时序、冷却、目标距离、伤害、击退、驻留与 UI。
- `sword.yml`：巨剑高度、下落物理和缩放。
- `effects.yml`：预警点数、能量轨道、拖尾粒子和裂纹数量。

## 已移除旧实现
`skill/SwordProjectile.java` 已从 V2.2.0 主分支移除。巨剑实体和模型职责现在完全由 `HeavenlySwordEntity` 与 `SwordModelController` 承担。

## 关键兼容行为
- 默认蓄力 40 ticks。
- 默认从目标上方 18 格生成。
- 默认落地驻留至少 4 秒。
- 保留分层范围伤害与击退。
- 驻留伤害不会反复击飞目标。
- 玩家 Pitch 不参与巨剑朝向。
- V2.1.20 的模型固定姿态逻辑保持不变。

## 实机测试重点
1. 从前、后、左、右和斜向释放技能，确认剑面始终水平朝向释放者。
2. 玩家抬头或低头释放，确认剑身不会跟随 Pitch 倾斜。
3. 蓄力阶段缩放从 `sword.yml` 的 start scale 平滑增长到 end scale。
4. 下落速度、加速度、最大速度与 `sword.yml` 一致。
5. 落地冲击特效出现一次，首次伤害只执行一次。
6. 驻留期间按 `skills.yml` 间隔持续造成伤害。
7. 驻留结束后 ItemDisplay 正确清理。
8. `skills.yml`、`sword.yml`、`effects.yml` 修改后重启服务器确认参数生效。
