# V2.2.0 — 天剑降临模块化版本

## 目标
V2.2.0 开始把技能从单体实现拆成技能编排、实体状态与模型显示三个职责层，同时保持现有技能数值与核心表现。

## 当前完成

### 1. 技能编排层
`skill/HeavenlySword.java`
- 负责目标选择。
- 负责 TARGET/CHARGING/FALLING/LINGERING 生命周期。
- 负责调度预警、能量、轨迹、冲击和伤害模块。
- 不再直接创建 `SwordProjectile`。

### 2. 实体层
`entity/HeavenlySwordEntity.java`
- 管理巨剑高度、下落速度、落地状态和驻留位置。
- 对外提供 `spawn / charge / beginFall / tickFall / land / keepLanded / remove` 等生命周期接口。
- 将视觉实现与技能流程隔离。

### 3. 模型层
`model/SwordModelController.java`
- 专门管理 ItemDisplay。
- 保留 V2.1.20 的 `+135° Z` 固定剑身姿态。
- 保留只使用水平 X/Z 计算玩家朝向的逻辑。
- 统一处理缩放、传送、Persistent、Invulnerable、亮度和 Billboard。

## 保持不变
- 蓄力 40 ticks。
- 巨剑默认从目标上方 18 格生成。
- 下落速度/加速度/最大速度继续读取现有配置。
- 原有分层伤害、击退和持续伤害配置保持兼容。
- 落地后至少 4 秒驻留。
- 玩家 Pitch 不参与剑身朝向。

## 注意
`skill/SwordProjectile.java` 在本阶段仍保留作为兼容旧实现的源码文件，但新技能路径已经通过 `HeavenlySwordEntity` 与 `SwordModelController` 工作。后续版本会在确认实机稳定后彻底移除旧实现。

## 测试重点
1. 从不同水平角度释放技能。
2. 玩家抬头/低头释放，确认剑身不倾斜。
3. 蓄力期间巨剑缩放正常。
4. 下落轨迹正常。
5. 落地后剑本体仍存在并至少驻留 4 秒。
6. 驻留期间持续伤害正常。
7. 技能结束后 ItemDisplay 被正确清理。
