# V2.1.18

## 本版本目标

以 V2.1.14 的核心姿态目标重新制作巨剑显示：

- 剑身垂直
- 剑尖始终向下
- 巨剑正面始终朝向释放技能的玩家
- 不受玩家 Pitch 影响
- 无论技能从哪个水平/方位释放，都保持上述姿态

## 本次修改

### 1. 巨剑模型变换

`SwordProjectile` 使用 ItemDisplay 的独立双侧旋转：

- LEFT rotation：X 轴 `90°`
- RIGHT rotation：Z 轴 `-135°`

不再使用 V2.1.17 的 Z `45°` 方案。

### 2. 面向释放者

每次更新剑模型时，根据：

`巨剑位置 -> 释放技能玩家`

计算水平 yaw。

只使用 X/Z 平面方向，不使用 Y/Pitch，因此玩家抬头或低头不会把剑身带歪。

### 3. 全生命周期保持

同一姿态应用于：

- 蓄力
- 开始下落
- 下落移动
- 命中落地
- 落地驻留

落地后的真实 ItemDisplay 继续保留至少 4 秒，并继续执行持续伤害。

## 实机验证重点

本版本安装后重点观察：

1. 抬头看天空释放，剑是否仍然垂直。
2. 剑尖是否明确朝地面。
3. 站在剑的不同方向释放，剑面是否始终朝向玩家。
4. 从正面、背面、左侧、右侧以及斜向释放，剑是否都保持相同规则。
5. 落地后 4 秒驻留与持续伤害是否仍正常。
